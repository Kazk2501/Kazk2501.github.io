# GiftsForKaz-If-You-Need-Ideas-
A website I've made that showcases a list of items that I'd like to have, continually updated by yours truly. 

## Use it

Open `index.html` in a browser. Use **Add an idea** to add an item with its description, picture URL, and shop link. New items are saved in the browser using local storage, so the list can be maintained without a backend.
Please don't take this as a sign of any distrust in people who want to get me a gift for something like a birthday or christmas or whatever. I made this website because there are plenty of things out there I'd like, and if someone isn't sure or doesn't know me that well, they can pick an item off this list and I guarantee you I will be satisfied with it.
